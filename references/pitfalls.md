# 踩过的坑（按出现顺序）

每一条都来自 2026-11-15 那次真实分析，并给出了当时的数值证据。

---

## 一、数据解读

### 1. 先确认 Spark 用的是 Processed 图

`Images/` 下是原始图，`ProcessingPlugin/Images/` 下是 SparkControl 处理过的：
Green 通道扣除了 20% Red，并做了背景扣除。

**证据**：只表达 mCherry 的对照孔（D8），原始 Green 与 Red 的相关系数高达 0.63；
换到 Processed 图后，Green 阳性面积降到 5×10⁻⁷（等于零）。如果用原始图算 G/R，
会得到 0.124 这种"假 GFP 信号"。

### 2. Processed 图也不能整图积分

Processed 图约 47% 的像素非零（正噪声本底），整图积分时空孔的"信号"
（约 4.3×10⁹）和最亮孔的信号（1.9×10¹⁰）只差 4 倍，信噪比完全被淹没。

**做法**：用空孔分布 p99.99 作阈值（本批 Green=16234、Red=7156），只积分超阈值像素。
此时空孔 G/R≈1.4，真实孔 0.03–0.18，区分度就出来了。

### 3. 2× 物镜对弱信号是致命的

Spark 2× 全孔成像，单个 15 µm 细胞在图上只有 5–6 个像素，低于 Counting 模块
8–30 µm 的尺寸下限，只能识别成团细胞。

**证据**：EL222 组（信号弱）的 Spark 绿色对象数 **0–2 个/孔**，
而 PhyB 组是 **43–141 个/孔**。所以 EL222 组只能用 EVOS 10×。

判断规则：如果某组的对象数中位数 < 5，该仪器对这组不可用，不要硬做统计。

### 4. 单个亮斑伪影能毁掉对照

EL222 的对照孔 B2 有一个亮斑，把对照 G/R 抬到 0.104（其余两孔 0.0002/0.0001）。
均值被拉到 0.035，导致所有突变体看起来"低于对照"，ANOVA P=0.48。

**处理**：
- 用 `gfp_in_rfp_frac`（面积比）或 `n_gfp`（细胞数）做交叉验证；
- 报告里如实说明该孔异常，不要偷偷剔除，除非有成像/污染证据。

### 5. 曝光不固定就没法比

EVOS 会在自动模式下逐图改曝光/增益。本批 45 个孔的 GFP 全是 48.35 ms / gain 14.44，
RFP 全是 103.26 ms / gain 32.74（写在 TIFF 的 OME ImageDescription 里），
所以孔间可比。**下次拍摄务必锁定手动曝光**；`01_quant_evos.py` 会检查并报警。

### 6. 8-bit 不等于定量

EVOS TIFF 是 8-bit 显示值（12-bit 截断到 0–4095 再映射）。只要曝光增益固定，
孔间比较仍然成立；但不要拿它当绝对荧光值。

## 二、定量

### 7. 必须做背景扣除，而且要局部

10× 视野的照明不均肉眼可见（边缘比中心亮 2–3 倍）。
用全局中位数扣除会留下梯度，导致"边缘的细胞看起来弱"。

**做法**：降采样 4 倍 → 25×25 中值滤波（等效 100 px ≈ 62 µm）→ 放大回原尺寸相减。

### 8. 分割参数

| 参数 | 值 | 说明 |
|---|---|---|
| 高斯平滑 σ | 2 px | 抑制 CMOS 噪声 |
| 阈值 | 4σ（MAD 估计） | 噪声极小时用绝对下限 2.5 |
| 开运算 | 1 次 | 去掉孤立像素 |
| 最小面积 | 40 px² ≈ 15 µm² | 10× 下细胞约 400–500 px² |

低于 4σ 会把背景纹理算成细胞；高于 6σ 会漏掉暗细胞。

### 9. 比值指标比绝对值稳

`reporter_index = Σ报告/Σ内参` 能同时消掉转染效率和细胞数差异。
本批同一构建三个复孔的 mCherry 积分相差 2–3 倍，但比值 CV 只有 20–60%。

### 10. 至少三个指标同向才下结论

本批用了：
- `reporter_index`（积分比）
- `gfp_in_rfp_frac`（被点亮细胞比例）
- `n_gfp`（阳性细胞数）

EL222 组三个指标给出的排序完全一致（L87I > E87D > G85R > AQTrip），
结论才敢写。若三个指标打架，说明信号在噪声水平。

**反例**：`median_gfp_per_cell / median_rfp_per_cell` 这个指标在本批完全不可用
（分母接近 0，排序乱跳），已从流程中删除。

## 三、统计与呈现

### 11. n=3 时别用 t 检验的 p<0.05 当唯一判据

本批 EL222 的 L87I：比值指标 p=0.101，面积比 p=0.049，细胞数 p=0.034。
三个指标方向一致但显著性边缘。报告里应同时给出倍数和相对活性，
并说明"动态范围小、结论为方向性"。

### 12. 相对活性要说明基线

`(x-ctrl)/(best-ctrl)` 在 ctrl≈0 时会被放大成几百倍（本批 L87I 是 430×）。
写报告时必须同时给出：
- 原始比值（4.0×10⁻⁵ → 1.7×10⁻²）
- 相对活性（100%）
- 一句"对照接近本底，倍数不宜过度解读"

### 13. 不要为了好看删点

异常孔（B2 亮斑）保留在数据里，在 QC 表和讨论中说明。审稿人会问。

## 四、出图

### 14. 图片拉伸 ≠ 定量

显微图展示时做了背景扣除 + 1–99.9% 百分位拉伸，**必须在图注里写明**。
定量永远用原始 8/16-bit 值。

### 15. 标尺要按真实像素尺寸画

EVOS 10× 是 0.619225 µm/px（从 OME 元数据读，不要猜）。
100 µm = 161.5 px。画在图像坐标系里，缩图时标尺长度不变。

### 16. 颜色

用 Okabe–Ito 色盲友好配色：
`#D55E00`（朱红）、`#0072B2`（蓝）、`#999999`（灰）、`#009E73`（绿）。
不要用红绿对比（色盲人群无法区分）。

### 17. 规格

- 双栏 183 mm / 单栏 89 mm
- Arial 7 pt，坐标轴 6.5 pt
- 线宽 0.5 pt，刻度朝外、长 2.5 pt
- 矢量 PDF（`pdf.fonttype=42` 嵌入字体）+ 600 dpi PNG
- 误差线 = 标准差；必须画复孔散点
- 显著性用 `*`、`**`、`***`，图注写清检验方法和对照

### 18. matplotlib 的坑

- `symlog` 坐标轴遇到负数会触发 minus glyph 警告 → 先把值 clip 到正值
- 中文标签要用系统字体（macOS: `Hiragino Sans GB` 或 `Arial Unicode MS`）
- `⁺` 上标在 Hiragino 里缺字 → 用 `$^+$` 或直接写 `+`

## 五、LaTeX 报告

### 19. 中文路径不能用 `\path{}`

hyperref 的 `\path` 会绕过 xeCJK 的字体映射，中文全部变成空白（
`Missing character: There is no 原 in font lmmono10`）。
改用 `\texttt{}`，并把下划线写成 `\_`。

### 20. 必须设 `\setCJKmonofont`

否则正文正常、`\texttt{}` 里的中文缺字。

### 21. 大图用非浮动环境

`figure[htbp]` 遇到 5–6 英寸高的图会连续堆积到文末，出现"附录前面突然冒出一张图"。
用：

```latex
\begin{center}
\includegraphics[width=\textwidth]{...}
\captionof{figure}{...}
\label{...}
\end{center}
```

配合 `\raggedbottom`。

### 22. longtable 宽度

六列以上容易 overfull 0.9 pt。加 `\small\setlength{\tabcolsep}{5pt}`。

### 23. 表格里的科学计数法

`7.98\times10^{-5}` 要包在 `$...$` 里；从 Python 生成时注意反斜杠数量
（raw string 里写一个 `\`，不要写 `\\`）。
