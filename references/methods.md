# 方法说明

## 1. 为什么用「报告基因 / 内参」的比值

同一孔内两个质粒共转染，细胞间的转染效率差异可达数倍。
内参（组成型 mCherry）与报告基因（诱导型 EGFP）在同一细胞里，
取比值即可把"转进去了多少质粒"约掉：

```
reporter index = Σ EGFP信号 / Σ mCherry信号
```

前提：
1. 两个通道曝光/增益在全板固定；
2. 通道间串色可忽略（用单质粒对照验证）；
3. 内参的表达不被处理条件影响（这里只比较不同突变体，条件相同）。

## 2. EVOS 图像处理

```
原始 8-bit
  → 大窗口中值滤波估背景（ds=4, k=25 → ~100 px）
  → 相减（保留负值，积分时负值不参与）
  → 高斯平滑 σ=2
  → 阈值 kσ（k=4，σ 由 MAD 估计）
  → 开运算 + 去除面积 < 40 px² 的连通域
  → 掩膜内积分
```

为什么用中值而不是高斯估背景：细胞是稀疏亮点，中值对亮点不敏感，
能正确估计"若没有细胞时的亮度"。

## 3. Spark 图像处理

```
Processed 图（已串色矫正 + 背景扣除，仍有正噪声本底）
  → 阈值 = 空孔分布的 p99.99
  → 超阈值像素积分
```

为什么不能用仪器自带的"全图平均值"：噪声本底占主导。
为什么阈值来自空孔：每批的噪声水平不同，不能写死。

## 4. 三个平行指标

| 指标 | 公式 | 敏感于 | 抗性 |
|---|---|---|---|
| reporter_index | Σ报告/Σ内参 | 总表达量 | 抗细胞数变化 |
| gfp_in_rfp_frac | GFP⁺面积 / mCherry⁺面积 | 被激活的细胞比例 | 抗单个亮点 |
| n_gfp | 连通域计数 | 细胞数 | 抗亮度差异 |

三者同向 → 结论可靠。

## 5. 统计

- 每组 n=3 复孔；每个复孔本身是独立转染孔。
- 组间：单因素 ANOVA（检验"至少有一个不同"）。
- 各变体 vs 对照：Welch t（不假设方差相等，n 小时更稳）。
- 不推荐在 n=3 时做多重比较校正（Dunnett/Bonferroni），
  因为校正后几乎没有显著项；报告里直接给出 p 值和倍数，让读者判断。

## 6. 相对活性

```
relative activity (%) = 100 × (mean_x - mean_ctrl) / (mean_best - mean_ctrl)
```

- 0% = 与阴性对照相同
- 100% = 组内最强
- 负值 = 低于对照（通常是表达/功能受损）

**局限**：分母是组内最大值，所以相对活性不能跨组比较（EL222 的 100% ≠ PhyB 的 100%）。
跨组只能比"倍数 over 对照"。

## 7. 仪器选择判据

| 判据 | 阈值 | 含义 |
|---|---|---|
| Spark 绿色对象数中位数 | < 5 | 该组 Spark 不可用 |
| EVOS GFP⁺ 细胞数中位数 | < 10 | 统计力不足，结论只作方向性 |
| 两仪器 Spearman ρ | > 0.9 | 互证可靠 |
| 两仪器 Spearman ρ | < 0.5 | 其中一台不可用，查对象数 |

## 8. 光依赖性的证明

本项目的数据只有"光照"条件，没有暗对照。因此：
- 能说：光照 20 h 后哪个突变体报告输出更强；
- 不能说：这个输出是光诱导的（可能是渗漏表达）。

要证明光依赖，需要同一板上加暗对照孔，比较 `light/dark` 比值。
报告里必须写明这一局限。
